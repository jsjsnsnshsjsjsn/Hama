# 🎮 Arena Strike

یاری شوتەری 3D لە جۆری پۆبجی — بە قەبارەی خۆمان. بە SceneKit دروستکراوە، بەبێ هیچ فایلی دەرەکی (هەموو گرافیک و دەنگەکان بە کۆد دروستدەکرێن).

## تایبەتمەندییەکان

- **تاکە یاری (١ڤ٤)**: تۆ بەرامبەر ٤ بۆت — ٤ ئاست: خراپ، باش، زۆرباش، ئەستێرەیی (زیرەکتر لە مرۆڤ)
- **١ڤ١ لەگەڵ هاوڕێ**: لە هەمان وایفای، بەبێ سێرڤەر (MultipeerConnectivity)
- **ئەی ئای بۆتەکان**: کۆ نابنەوە، هەرگیز لە جێگایاندا ناوەستن، فلانک دەکەن، سترەیف دەکەن، لە کاتی مردن ڕۆڵی نوێ وەردەگرن (ڕاشەر/فلانکەر/مارکسمان/بەرگریکار)
- **چەکەکان**: M416 + AKM — هەموو باشترین ئەتاشمێنتەکان دانراون (کۆمپەنسەیتەر، گریپ، گوڵەی درێژ، ستۆک)
- **سکۆپەکان**: ئاسن، هۆلۆ، 2x، 3x، 4x، 6x، 8x — سوڕانەوە بە دوگمە
- **FPP + TPP** — گۆڕین بە دوگمە لە کاتی یاری
- **سێنسیڤیتی بە دڵی خۆت**: سێنسیڤیتی ئامانجگرتن + سکۆپ لە ڕێکخستنەکان
- **کاتی یاری**: ١–١٠ خولەک — براوە = زۆرترین کوشتن
- **قەبارەی ئەرێنا**: بچووک (40م) / مامناوەند (60م) / گەورە (80م)
- **کوالیتی وێنە**: Low / HD / HDR / UHD
- **FPS**: 30/45/60/90/120 — خۆگونجاندن بەپێی توانای ئامێرەکە (90+ تەنها لە ProMotion)
- نەخشەی بچووک، فییدی کوشتن، HP، گوڵە، سپاونی خێرا، ڕیزبەندی کۆتایی

## کۆنترۆڵەکان

| کردار | دوگمە |
|---|---|
| جوڵە | جۆیستیکی چەپ |
| ئامانجگرتن | دراگکردن لە شاشەکە |
| تەقە | دوگمەی خوارەوە-ڕاست (پەنجە ڕاگرتن = ئۆتۆماتیک) |
| سکۆپ (ADS) | دوگمەی سکۆپ |
| گۆڕینی سکۆپ | دوگمەی سوڕانەوە |
| بازدان / نیشتن | دوگمەکانی خوارەوە-ڕاست |
| FPP/TPP | دوگمەی چاو |
| گۆڕینی چەک | دوگمەی چەک |

## دروستکردنی IPA (هەمان ڕێگای AIEnhancer)

1. ناوەڕۆکی ئەم فۆڵدەرە بۆ ڕیپۆیەکی GitHub بفرستە (فۆڵدەری ArenaStrike و .github لە ڕیشەدا)
2. لە GitHub: **Actions** → workflowـەکە دەست پێبکە
3. لە artifacts: `ArenaStrike-unsigned.ipa` دایگرە
4. بە ESign یان AltStore دایمەزرێنە

## ڕاستییە تەکنیکییەکان

- 90/120 FPS تەنها لە ئایفۆنە ProMotionـەکاندا (13 Pro+). لە ئامێرە کۆنەکاندا خۆکارانە دادەبەزێت بۆ 30/60 — ئەمە سنووری ڕەقەکاڵایە نەک کۆد
- ١ڤ١ لەسەر ئینتەرنێتی دوور پێویستی بە سێرڤەرە — وەشانی ئێستا هەمان وایفایە
- هەموو گرافیک و دەنگەکان بە کۆد دروستکراون — هیچ فایلی دەرەکی و هیچ زانیارییەکی نهێنی نییە
